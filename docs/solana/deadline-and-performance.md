# 活动截止时间与设置页面改进（0.4.6+9）

在任务配置的调度设置中勾选“启用活动截止时间”，选择日期和时间，再保存。界面按当前电脑本地时间显示，保存明确时区；原有不带时区的日期仍按后端本地时间解释。

到期后，后端会自动取消**该任务的启用勾选**并保存配置，截止日期保留。配置停止时也会检查；后端关闭期间不会执行检查，下次后端启动后补处理。正常检查间隔为 1 秒。关闭截止开关保存后，不限制截止时间。要再次运行已过期活动，需要先延后或关闭截止设置，再启用任务。

到期任务不会再获得新的执行批次。正在运行且支持安全边界的任务在安全位置结束；其他任务完成本次执行后不再开始下一次。其他任务继续调度。自动停用写入操作审计，延长或取消截止时间时会在配置锁内重新核验，不会用旧缓存覆盖新设置。

当前设置页会同步自动停用结果。如果还有未保存的修改，会保留草稿并提示重新加载核对，避免覆盖后端已停用的状态。

## 中文设置

配置中文词典随客户端内置，覆盖 57 个注册设置页。字段名、枚举显示和帮助使用中文；原始 JSON 键、协议值、用户填写的内容保持原值。更新后端追加词典后，运行 `python dev_tools/sync_oasx_translations.py`；`--check` 可检查词典和配置目录是否同步。

## 页面性能

- 长表单按可见字段创建控件，离屏字段释放，草稿保存在内存。标题和说明共用文字选择区域。
- 实时事件合并为每秒最多一轮状态刷新，只查询总览和调度；统计、审计和存储仍由 15 秒轮询及手动操作刷新。
- 一轮后台刷新合并通知，设备截图只在内容变化时解码，背景绘制与动态内容分离。

离线 720×600、200 字段场景，首屏输入控件从旧版一次构造 200 个变为 5 个；这不是实际 FPS 测量。回归覆盖滚动后草稿保留、立即保存、折叠恢复、连续事件刷新、截图缓存及到期事件与保存应答并发。
