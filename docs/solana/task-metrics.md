# 当前任务、战斗与本轮任务进度

本次按当前 `ConfigMenu` 的实际可执行菜单逐项核对，共 **55 个任务**，不包含“脚本”“全局配置”、工具或没有执行入口的 OrochiMoans 配置。机器可读清单见 [task-metric-coverage.json](task-metric-coverage.json)。

- **当前值**：所有任务都有完整生命周期的 `0/1 项`，仅明确成功后变成 `1/1 项`。其中 19 个任务进一步上报已检查过语义的真实计数，单位随任务显示。初始化、异常、业务跳过不会伪造完成数量。
- **战斗次数**：35 个有战斗执行路径的任务接入实际结算。新运行从“本次已观测结算 0 次”开始；准备、进入战斗、超时或退出不算结算，同一结果页重复出现只计一次。20 个非战斗任务返回“不涉及战斗”，而非一直“待上报”。旧版本未采集到的战斗历史不回填。
- **任务进度**：沿用服务端执行会话的生命周期统计，55 个任务均能进入本轮计划；只有真实成功记录才增加已完成任务数。单任务重试不会重复增加，同一配置不会读到其他配置的进度。

截图中的地域鬼王此前显示“暂不支持”，原因是客户端已更新而生产后端仍是旧的指标采集代码。本次必须一起部署后端采集/投影代码，单独替换客户端不能获得这些真实数据。
