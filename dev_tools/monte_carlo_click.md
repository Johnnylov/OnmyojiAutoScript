# 蒙特卡洛收束随机点击

统一实现：`module/base/random_click.py` 中的 `monte_carlo_click_point(roi)`。
ROI 格式沿用 `(x, y, width, height)`，返回两个 Python 整数。

每次调用独立进行以下计算：

1. 在当前窗口内随机产生 32 个二维候选点。
2. 按归一化后距 ROI 几何中心的距离，保留最近的四分之一候选点，用其均值估计新窗口中心。
3. 窗口宽高各乘 0.65，重复 3 轮；窗口宽高最低保留可用区域的 30%。
4. 在最终窗口内随机抽取一个坐标，不直接点击候选均值或几何中心。

这是单次点击内部的几何收束，不会读取点击成败，也不跨点击积累状态。没有额外的设备点击或等待。

## 边界与参数

- 默认向内留出每边 5% 的整数像素边距，小目标的边距向下取整。
- 正尺寸 ROI 使用左上包含、右下不包含的边界，避免点击到右侧或下方相邻区域。
- 零宽或零高沿用固定坐标语义；单像素轴固定在该像素。
- 多像素小目标保留至少一像素的采样半径，避免收束后只剩一个中心像素。
- 负尺寸、非有限坐标以及不包含整数像素的正尺寸区域报错。
- 参数可通过函数关键字覆盖；公共调用默认使用统一默认值：
  `samples=32, rounds=3, contraction=0.65, min_spread=0.30, inset=0.05`。
- 可传入 NumPy 随机生成器 `rng` 复现实验；默认兼容现有 `np.random.seed()`。
- 本函数保证目标 ROI 内的边界；调用方仍负责提供屏幕内的有效 ROI。

## 接入范围

已接入固定区域点击及其长按继承、图片前置/后置区域、OCR 全文匹配区域及其他模式的 ROI、GIF 区域、通用邀请组件的区域点击。
现有 `coord()` / `coord_more()` 接口不变。

明确指定坐标的 `device.click(x, y)`、任务特定的坐标偏移、滑动路径和等待时间沿用原逻辑。它们没有统一的目标矩形，不能在设备层再次随机偏移而保证不出界。

## 验证与生效

在脚本根目录运行：

```
toolkit/python.exe -m unittest discover -s dev_tools -p test_monte_carlo_click.py -v
```

离线检查覆盖坐标边界、细长区域、小目标、零尺寸、随机种子、中心收束、随机范围下限、计算轮数上限，以及各接入入口选择的 ROI。测试不操作设备或启动 OCR/图片服务。

一万次 1000×600 区域的离线采样中，归一化平均中心距离约从 0.212 降至 0.106；本机每次坐标计算约 0.12 毫秒。该结果仅代表采样分布和本机计算耗时，不代表实机点击成功率。

源码加载于脚本后端进程；已启动的进程需要重新启动后才会使用更新。未自动中断正在运行的任务。
