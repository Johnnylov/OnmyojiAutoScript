# 月华流光

在「活动任务 → 月华流光」中配置。任务默认关闭，默认挑战 **1 次**、最长运行 **90 分钟**，次数、预设队伍、绿标及战斗超时均使用本任务的独立配置。挑战次数设为 0 时不进入挑战。

任务从庭院右侧寻找「月映千灯」入口，再进入「月华流光」。每次挑战至少需要 6 点资源；第一次读数不足时，会重新截图再检查一次，连续不足就结束。只在挑战页识别到按钮后点击一次，确认进入准备、战斗或战斗结算页后计为一次挑战，失败也占用一次。通用奖励弹窗不计为进入战斗，连战强制关闭，因此同一次挑战不会重复计数。

仅当弹窗同时识别到「奖励已达获取上限」与「继续挑战」时继续；资源购买及其他未知确认弹窗会取消。沿用本地 Monte Carlo 点击和通用战斗框架。每次入口导航或战后返回都有 45 秒总时限；挑战后等待进入战斗最多 30 秒。活动结束、入口消失、页面变化或返回失败时抛出导航/识别错误，交给现有调度器的异常恢复流程，不会继续盲点挑战。运行时限属于软限制，到达后不再开始下一场，当前战斗由单场战斗超时保护。

建议首次启用保持 1 次，确认当前活动入口、资源识别与战后返回正常后再增加。素材适配 1280×720；离线回归无法替代当前游戏活动的实机验证。
