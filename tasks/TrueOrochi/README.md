# 真·八岐大蛇双开组队

重启 OAS 后端并刷新 OASX 的真·八岐大蛇设置后，可以使用新配置。

同一台电脑、同一个后端目录的两个配置各操作一个模拟器。在两个配置中：

1. 启用真蛇任务和「真蛇双开组队」。
2. 互填「队友 OAS 配置名」，如 `oas1` 填 `oas2`、`oas2` 填 `oas1`，不带 `.json`。
3. 一方设为初始队长，另一方设为队员。
4. 两边的「真蛇好友邀请」各填对方的一个游戏好友名。与其他组队任务相同，使用 OCR 查找好友；轮换后会反向邀请。
5. 按各自阵容填写原有的御魂切换项（分组/队伍序号或名称），同时运行双方的真蛇任务。等待时间可在邀请配置中调整。

切换御魂阵容后回到探索页面，识别「真·八岐大蛇」图标右上角的次数，直接点击该图标进入真蛇详情页。核对奖励次数和创建队伍都从这个入口进入。红色角标中的数字较细时，会先提取数字笔画再识别；无法可靠读取时仍按未完成重试。

开车模式以初始队长的设置为准。默认每周随机抽取队长两次、各一次、队员两次中的一种，也可固定选择。入口图标的红色数字与详情页的本周剩余奖励分别识别；OCR 不确定时不建队。每轮结算、退出房间后重新核对次数，指定开车方没有入口时由另一方建队。双方都没有入口时延后重试；双开模式不自动刷十层触发真蛇。

每个房间都检查「不公开（仅邀请）」选中后才创建。队长核验中间位置已有队友，并收到队员入队确认后点击挑战。若队员端未识别到房间，队长也可在双方本轮已就绪的前提下，连续两帧用御魂通用 OCR 核对中间位置的指定好友全名，再点击挑战；第三个空位不影响两人开车，已占用的位置不会重复点击邀请。

进入配置页后，双方识别「配」标题和右下角「准备」按钮，点击准备后继续十层自动战斗。日志分别记录入队核验、点击挑战和点击准备。结算时关闭头像框弹窗、点击退出，并等待双方都处理完再进行下一轮。失败、邀请超时、队友停止或 OCR 失败不增加成功次数。每周最多记录两次奖励，实际到下一周才重置计数。

好友姓名识别、完整名字匹配和选中标记核验复用普通御魂的通用邀请组件。真蛇邀请面板先查找当前页，再根据 OCR 得到的页签位置切换寮友、好友、跨区等列表。未选中指定名字时停止邀请；邀请按钮等待也有超时限制。

双开协调只读对方配置，运行状态保存在 `config/.runtime/true_orochi/`，不修改对方的调度或御魂设置。须同时运行双方的真蛇任务；本功能不自动启动另一份配置。未启用双开时保持单人模式及十层触发入口选项。

点击中断后，进程持有的运行锁会自动释放。重新运行双方任务时会清理旧轮次并重新识别游戏次数，保留本周随机开车方案和已获得的奖励次数。仍在运行的同名配置不允许重复启动。同步、识别或邀请异常会标记为未完成并在两分钟后重试；双方都无入口则按失败间隔等待，不记为成功结束。

验证使用用户提供的入口、建队、好友入队和准备页截图进行离线回归，覆盖真实 OCR、图片缩放与偏移、跨进程随机方案同步、强制中断后立即重启、调度重试、双方任务轮换邀请、私密开房和战斗收尾。双配置截图回放还覆盖队员未确认入队时，队长核验好友后挑战、双方点击准备的连续流程；实机十层战斗和头像框收尾仍需运行确认。

从后端目录运行回归：`toolkit\python.exe -m unittest discover -s dev_tools -p "test_true_orochi_*.py" -v`。
